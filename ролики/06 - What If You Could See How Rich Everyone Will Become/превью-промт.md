# Превью ролика 06: промт и команда
Одна попытка (правило владельца 12.11.2026), стиль строго по `канал-оформление/стиль-превью.md`. **Цена одной попытки ≈ $0,064** (`gpt-image-2.5-sunburst`, `high`, 1536x1024, два референса). Запуск только после «ок» владельца. Потом обрезка `scale=1280:-1,crop=1280:720:0:12`.

Сюжет (по референсу владельца): Leon слева с синим числом $61,400, Walt справа у кирпичной стены с огромным зелёным $6,310,000,000, заголовок «WHAT IF YOU COULD SEE / HOW RICH EVERYONE WILL BECOME?».

Команда (из корня репозитория):
```
python3 tools/openai_image.py --model gpt-image-2.5-sunburst --quality high --size 1536x1024 \
  --ref канал-оформление/эталон-превью-утверждён.png \
  --ref "персонажи/варианты-героя/эталон-мальчик-кепка-молния.png" \
  --prompt "$(cat "ролики/06 - What If You Could See How Rich Everyone Will Become/промт.txt")" --out "ролики/06 - What If You Could See How Rich Everyone Will Become/превью-gpt-1.png"
```
