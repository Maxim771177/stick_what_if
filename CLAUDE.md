## Куда складывать файлы
Только в эту папку. Видео и звук в GitHub не храним (см. `.gitignore`), они остаются на Mac.

## Всё сохранять в файлы
Всё, что готовится для канала, сохраняется файлом в эту папку; в ответе называется имя файла.

## Сразу в main
Любая правка правил, скилов или файлов ролика — сразу коммит и пуш. GitHub Action `.github/workflows/sync-to-main.yml` вливает ветки `claude/*` в `main`.
