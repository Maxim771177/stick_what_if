## Рендер видео: строго только на компьютере владельца
В облаке (в этой сессии) видео НЕ рендерим ни целиком, ни «черновик», ни «в фоне». Нельзя запускать `node render.mjs` без `--from/--to`, `--sheet`, `--stills`, `--styles` и `--bench`. Разрешено только короткое: листы кадров, стоп-кадры и превью до 45 секунд (`--from/--to`, `--scale 0.5`) для проверки.
Это правило про облачную сессию. В сессии, которая запущена локально на компьютере владельца (приложение Claude, вкладка Code, локальная папка), рендерить можно и нужно самому: взять установленный Chrome через `CHROME_PATH`, не скачивать отдельный браузер.
Полный рендер, черновик и финал из облачной сессии: собрать архив `python tools/pack_render.py --project projects/<slug> --lang ru --resolution 1080p --out "ролики/<ролик>/render-kit-<slug>.zip"` и отправить владельцу файлом с инструкцией (Mac: в Терминале `bash `, перетащить `RENDER-Mac.command`, Enter). Звук микшируется скриптом на Mac. Если очень хочется рендерить в облаке, сначала спросить и получить явное разрешение.

## Картинки и анимация (с 08.11.2026): всё кодом, картинки через OpenAI
- Анимация и сборка ролика: ТОЛЬКО скриптом в плагине Razgon, рендер на Mac владельца. Higgsfield не используем вообще: ни клипы Wan 2.7, ни картинки (дорого). Любые правила про «клипы Wan» и «Анимация роликов» считать отменёнными.
- Картинки для листов (сложные предметы, сцены, персонажи, 6–10 штук на листе на зелёном фоне #00FF00, потом нарезка листа на отдельные файлы) генерируем через OpenAI Images API скриптом `tools/openai_image.py`. Ключ только в переменной окружения `OPENAI_API_KEY` на Mac владельца, в файлы, коммиты и ответы его не пишем. Модель по умолчанию `gpt-image-2.5-flare` (чище и проще), для сложных предметов с деталями `gpt-image-2.5-sunburst`; качество `low` для поиска, `medium`/`high` для финала. Эталон героя подаётся как `--ref`.
- **Принцип «гибрид» (решение владельца 08.11.2026).** Богатые фоны сложных сцен и сложные предметы (столовая, спортзал, класс, автобус, офис и т.п., где код выглядит бедно) делаем через OpenAI: по эталону героя как `--ref`, листы по 6–10 предметов на зелёном фоне, нарезка `razgon-animation-studio/tools/sheet_cut.py`. Какие сцены сложные, выбирает Claude по раскадровке (в ролике 01 это ≈15 мест + пруд, ≈16 фонов и ≈25 листов предметов, ≈$0,5–1).
- **Фоны мест по умолчанию от OpenAI (с 08.11.2026, ролик 01 уже так собран).** Для каждого места ролика: один пустой фон без героев и без надписей (`gpt-image-2.5-sunburst`, `medium`, референс — кодовый кадр места), файл `projects/<slug>/assets/bg/<место>.png` (1536x1024, в кадре обрезается до 16:9). Подключение: список `BG_SETS` в `scenes/lib.js` (`BG_IMG=false` вернёт кодовые фоны). Абстрактные места (void: линейки, сетки, графики), планы сверху и плашки остаются кодом. Цену и «ок» перед запуском см. выше.
- **Персонажи и действие всегда кодом** (Razgon): Leon и остальные одинаковые во всех кадрах и двигаются. Героев GPT не рисует и в кадр готовыми не вставляется (плывёт внешний вид). Если GPT нарисовал героев на фоне, фон берём без них (в промте: «empty scene, no characters»).
- Из картинок GPT убираем выдуманные надписи (плакаты, меню): либо просим в промте «no text on signs», либо закрываем кодом.
- Порядок: Claude делает листы/фоны, показывает сеткой на проверку (как обычно), после «ок» нарезает и кладёт в `assets` проекта, затем кодом ставит героев поверх.
- Всё остальное (стикмены, надписи, эффекты, листы кадров, рендер) делается кодом, без генерации.
- **Цена всегда согласуется до запуска (правило владельца 08.11.2026).** Перед ЛЮБОЙ генерацией через OpenAI (даже одна картинка) Claude пишет: что собирает, сколько картинок/листов, модель и качество, сколько это в долларах (по токенам: выход $30 за 1 млн, вход с референсом $8, текст $5; ориентир: лист `low` ≈ 0,5 цента, фон `medium` ≈ 1,1 цента, с эталоном ≈ 2,3 цента, `high` ≈ 5 центов и больше), и запас на пересъёмку. Запускает только после явного «ок» владельца. После запуска называет, сколько реально потрачено.

## Самопроверка кадров (с 13.11.2026): владелец кадры не пересматривает
Владелец даёт ссылку/угол и озвучку, всё остальное Claude проверяет сам до показа. Полный список «ошибка → правило → проверка» в `уроки-визуала.md` (читать до сборки сцен), порядок проверки в скиле `frame-self-check` (раздел 9).
- **Глаза всегда видны** у всех персонажей. Кепки только `capBack`; козырёк, чёлка, рука не закрывают глаза.
- **Герой всегда целиком в кадре** (голова и ступни). Если он гигант, не увеличиваем героя (≈ s 3.4), а уменьшаем всё вокруг; рядом всегда эталоны масштаба (люди, машины, дома). Лицо или стопа крупно только врезкой рядом с общим планом.
- **Окружающие реагируют** на событие (глаза вверх, лицо «шок»).
- **Позы героя без расставленных ног**: `ready`, `kick`, `crouch` не использовать, шаг делать через `walk`.
- **Предметы по логике места** (на тротуаре, а не на проезжей части), раструб мегафона от рта, один размер животного в цепочке сцен, лица во врезках не обрезаны, руки человеческие, подписи не закрывают голову, гэг читается без звука.
- **Автопроверка в коде**: в `scenes/lib.js` проекта есть `frameCheck` (печатает `ERROR frame-check` при выходе героя за кадр) и `freeX` (подписи уходят от головы). При создании нового проекта копировать их из `projects/what-if-double-size/scenes/lib.js`. После каждой сборки: `node render.mjs --project ... --sheet`, в выводе не должно быть строк `ERROR`.
- **Порядок перед показом**: лист кадров в середине И в конце каждой сцены (два прохода), сверка с `уроки-визуала.md`, исправление, повторный лист исправленных сцен, владельцу одной строкой «что нашёл и исправил сам».

## Синхронизация между компьютерами (с 09.11.2026)
Владелец работает на двух компьютерах с одним аккаунтом Claude. Репозиторий GitHub (`Maxim771177/stick_what_if`) — единственный источник правды для текста, кода и настроек; большие файлы живут на Google Диске.
- **Автоматически, без вопросов:** после каждой законченной правки файлов в проекте (не реже, чем в конце каждого ответа, где что-то менялось) Claude делает `git add` нужных файлов, коммит с понятным русским сообщением и пуш. Владелец об этом не просит и не подтверждает.
- **Пуш с Mac:** `git -c credential.helper= -c credential.helper='!/opt/homebrew/bin/gh auth git-credential' push origin HEAD` (обычный `git push` падает, `gh` вне PATH).
- **Не коммитить:** случайный мусор (`.scratch/`, временные файлы) и чужие незакоммиченные правки, которых Claude не делал и не понял; про них сказать владельцу одной строкой.
- **В начале сессии** (первое сообщение на компьютере): `git fetch`, и если `main` или ветка ушли вперёд, сделать `git pull --rebase` (или влить `main`) до начала работы. При расхождении или конфликте остановиться и сказать владельцу.
- **В конце работы:** `git status` должен быть чистым, ветка запушена. В последней строке ответа сказать, что синхронизировано (хэш коммита), чтобы владелец мог спокойно переходить на другой компьютер.
- **Память Claude** (`~/.claude/projects/...`) на компьютерах не синхронизируется. Всё важное для работы над проектом записывать сюда, в `CLAUDE.md`, а не в память.
