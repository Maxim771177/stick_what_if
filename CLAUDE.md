# Правила работы в этой папке (канал «What if», английский, стикмены)

Новый канал, сделан как дубль lr-stick (06.11.2026). Принцип создания роликов тот же, логика и язык другие.

- Канал: английский язык озвучки и надписей, стикмены, формат «What if».
- Сценарии, транскрипты конкурентов, профиль канала: скил `video-script` (`скилы/video-script/SKILL.md`).
- Визуал и раскадровка: скил `video-visuals` (`скилы/video-visuals/SKILL.md`).
- Монтаж и рендер: плагин Razgon Animation Studio (`razgon-animation-studio`), рендер идёт на Mac владельца.
- Порядок этапов — `этапы-ролика.md`; теги озвучки — `теги-озвучки.md`.

## Куда складывать файлы
Только в эту папку. Видео и звук в GitHub не храним (см. `.gitignore`), они остаются на Mac.

## Всё сохранять в файлы
Всё, что готовится для канала, сохраняется файлом в эту папку; в ответе называется имя файла.

## Сразу в main
Любая правка правил, скилов или файлов ролика — сразу коммит и пуш. GitHub Action `.github/workflows/sync-to-main.yml` вливает ветки `claude/*` в `main`.
