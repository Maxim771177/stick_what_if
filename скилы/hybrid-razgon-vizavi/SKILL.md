# Гибрид Razgon + vizavi-motion

Решение владельца 25.11.2026 по тесту первых 26 секунд ролика 11: «движение Razgon лучше, а детали, движение камеры и динамика от нового скилла лучше. Дальше двигаемся так».

## Что откуда берём

| Что | Откуда | Где в коде |
|---|---|---|
| Герои (рисунок, наряды, лица, чуб и кепка Leon) | Razgon, `engine/rig-doodle.js`, пак `doodle`, вариант `clean` | `drawCharacter` из `/engine/characters.js`, наряды `OUTF` в `шаблон/scene.html` (копия `OUT` из `scenes/lib.js` проекта) |
| Движение героев (позы, ходьба, удар) | Razgon: `POSES`, `posesAt`, `walkPose`, `breathe` | `actors()`, режим `?motion=razgon` (по умолчанию) |
| Камера | vizavi: сплайн по ключам, пролёты, наезды, крен, тряска на ударе | массив `K` и `cam(t)` |
| Глубина | vizavi: дальний, средний, ближний планы с параллаксом, размытие дальнего и ближнего (DOF) | `farLayer`, `midLayer`, `nearLayer` |
| Размытие движения | vizavi: 4 подкадра на кадр | `window.draw` |
| Надписи | vizavi + стиль «комикс и стикеры»: вывески на палатках, табличка с выскакивающими словами, взрывы `WHAM!`, цифры, плашки | `stickers()`, `signTexts()`, `stall()` |
| Реакции толпы | vizavi: на удар и на сюрприз толпа Razgon поднимает руки, лица «удивлены» | `crowdPerson()` |
| Звук | vizavi: музыка и SFX под действие (поп стикера, свист пролёта, удар, тики счёта) | `audio.py` |
| Белая вырубка стикера вокруг героев | стиль «комикс и стикеры» (`../vizavi-motion/стили-промты/04_komiks_i_stikery.txt`) | `drawFigure()` |

Режим `?motion=vizavi` оставлен для сравнения (движение нового скилла: наклоны, сжатие и растяжение). Рабочий режим для роликов: `razgon`.

## Папки

```
скилы/
  vizavi-motion/                  скилл vizavi целиком, без правок (SKILL.md, references/)
    стили-промты/                 12 коротких описаний стилей (комикс, тушь, пиксели…)
  hybrid-razgon-vizavi/           этот скилл
    SKILL.md                      то, что вы читаете
    шаблон/
      scene.html                  сцена-эталон (ролик 11, первые 31 с озвучки): мир, камера, герои, стикеры
      render.mjs                  рендер кадров через Chrome + ffmpeg (1080p, 60 fps)
      audio.py                    музыка и SFX, синтез кодом
      собрать.sh                  всё одной командой
    эталон/сравнение-A-B.png      кадры утверждённого теста
ролики/11 - What If Your Punch Hit With 3 Tons of Force/
  гибрид-vizavi-razgon/           готовые видео теста: A (движение Razgon, утверждено), B (движение vizavi)
  тест-vizavi/                    первый тест «чистый vizavi» (стиль комикс, свои фигуры) и старая версия Razgon для сравнения
```
Видео (mp4) в GitHub не хранятся, лежат на Mac в папках роликов (см. `большие-файлы.md`).

## Как запустить

Из корня репозитория, на Mac владельца (рендер только там, правило CLAUDE.md):
```bash
bash скилы/hybrid-razgon-vizavi/шаблон/собрать.sh "ролики/NN - Название/гибрид" "ролики/NN - Название/озвучка.mp3" razgon
bash скилы/hybrid-razgon-vizavi/шаблон/собрать.sh "ролики/NN - Название/гибрид" "ролики/NN - Название/озвучка.mp3" razgon stills   # только стоп-кадры для проверки
```
Нужны Chrome (`CHROME_PATH`), `ffmpeg`, `python3` с `numpy`, и `razgon-animation-studio/node_modules` (playwright). Озвучка ускоряется ×1,2 внутри скрипта, как в канале.

## Как собрать новый ролик в этом стиле

1. Раскадровка и тайминги слов по `video-visuals` как обычно. Для каждой сцены 3–5 вариантов, выбранный записать (правило vizavi).
2. Скопировать `шаблон/` в `ролики/NN/гибрид-код/` и править там: список событий (времена ударов, появления героев), ключи камеры `K`, актёров `actors()`, стикеры `stickers()`, мир (`midLayer`: палатки, предметы), SFX в `audio.py`. Что общее для всех роликов (функции камеры, слоёв, стикера-вырубки, подкадров) не менять без причины.
3. Правила vizavi, которые держим: камера движется всё время (кроме технической паузы), три плана с параллаксом, надписи участвуют в действии (вешаются на предметы мира, выскакивают в ритм слов), у предметов вес и реакция, звук синхронен событиям, конечный кадр читаем.
4. Правила канала, которые держим (из `уроки-визуала.md` и `логика-кадров.md`): глаза видны, герой целиком в кадре (ступни не обрезаны), окружающие реагируют, предметы по логике места, гэг читается без звука.
5. Самопроверка: `собрать.sh … stills`, смотреть стоп-кадры, потом `frame-reviewer` (как в CLAUDE.md), исправить, только потом полный рендер.
6. Герой Leon только кодовой куклой Razgon (`ONE_LEON`); новые герои сначала один кадр владельцу на «утверждён».

## Ограничения (на 25.11.2026)
- Шаблон собран под один ролик (31 с). Для полного ролика (~9 минут) нужно разбить сцены по файлам и подгружать по времени; пока это не сделано. Следующий шаг: вынести ключи камеры, событий и актёров в данные по сценам, как в `story/shots.json` Razgon.
- Фоны в шаблоне нарисованы кодом (комикс). Богатые фоны от OpenAI (правило «гибрид» в CLAUDE.md) в гибрид пока не подключены.
- Звук синтезируется кодом и простой. Для финала можно заменить музыкой и SFX из библиотеки (Epidemic Sound подключён).
- Рендер ~90 секунд на ролик в 26 секунд на M-чипе.
