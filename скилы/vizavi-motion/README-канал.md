# Скилл vizavi-motion у нас в канале

Файлы скилла (`SKILL.md`, `references/`) — копия из `vizavi_motion-v1.6.1.zip`, которую владелец дал 25.11.2026. Не правим, чтобы можно было обновить заменой. Проверено: внутри только Markdown, без скриптов.
`стили-промты/` — 12 коротких описаний стилей из папки владельца «Стили - промты».

Как используем: целиком скилл не запускаем. Берём его принципы динамики (камера, глубина, размытие, звук, надписи) в гибриде с Razgon: `../hybrid-razgon-vizavi/SKILL.md`.
Выбранный стиль для «What if» с стикменами: `04_komiks_i_stikery.txt` (комикс и стикеры). Другие стили (тушь, пиксели, бумага) пробуем по просьбе владельца тем же способом на тех же 30 секундах.
