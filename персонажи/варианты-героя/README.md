# Варианты героя-мальчика (черновики, 06.11.2026)

Генерация: Higgsfield, модель gpt_image_2_6, качество low, 1k, 16:9, ~0,25 кредита за картинку. Это поиск направления, не эталон. Эталон делается после выбора, в высоком качестве.

Общая основа: стикмен-мальчик ~10 лет, круглая белая голова, толстый чёрный контур, глаза-точки, тонкие руки и ноги.

1. `вариант-1-жёлтая-худи.png`: жёлтая худи, синие шорты, белые кроссовки, три торчащих волоска.
2. `вариант-2-кепка-молния.png`: бирюзовая кепка задом наперёд, красная футболка с молнией, серые шорты, оранжевые кроссовки.
3. `вариант-3-шарф-очки.png`: оранжевый шарф, круглые очки, футболка в зелёную полоску, коричневые ботинки, один завиток.

Замечания по картинкам: у варианта 2 волосы вышли коричневыми (заказывались как у остальных, чёрные), у варианта 1 худи толще «стиковых» рук. Всё поправимо на этапе эталона.
