# Инструкция для Claude на втором компьютере владельца

(Владелец вставляет этот файл целиком в первый чат на новом Mac. Дальше Claude делает всё по шагам, команды выполняет сам, владельцу пишет по-русски и просто: владелец не работает в терминале.)

## Контекст
- Проект: канал «What if» (английский, стикмены). Репозиторий: https://github.com/Maxim771177/stick_what_if (аккаунт GitHub Maxim771177).
- Тот же аккаунт Claude, что и на первом компьютере. Файлы проекта живут в GitHub, программы и ключи ставятся на каждый Mac отдельно. Большие файлы (видео, звук) лежат на Google Диске и в GitHub не идут.
- Ничего не делай на этом компьютере в облачном режиме: нужна локальная сессия (приложение Claude, вкладка Code, локальная папка).

## Шаги (выполняй по порядку, после каждого проверяй результат)
1. **Homebrew, git, gh, node.** Проверь `which brew git node` и `ls /opt/homebrew/bin/gh`. Чего нет, поставь (`brew install git gh node`). Если нет самого Homebrew, скажи владельцу: установка просит его пароль, выполнить её должен он сам (команда с brew.sh).
2. **Вход в GitHub.** `gh auth status`. Если не авторизован, скажи владельцу выполнить в Терминале `gh auth login` (GitHub.com, HTTPS, вход через браузер аккаунтом Maxim771177) и дождись. Пароли и токены не вводи сам.
3. **Клонирование.** `git clone https://github.com/Maxim771177/stick_what_if.git ~/stick_what_if`. Попроси владельца открыть эту папку в приложении Claude (Code → выбрать папку), чтобы подхватились `CLAUDE.md` и правила проекта.
4. **Зависимости.** В `~/stick_what_if/razgon-animation-studio` выполни `npm install`.
5. **Chrome.** Проверь, что Google Chrome установлен (`ls "/Applications/Google Chrome.app"`). Для рендера используется `CHROME_PATH`, отдельный браузер не скачивать.
6. **Google Диск для компьютера.** Если не установлен, попроси владельца скачать с google.com/drive/download и войти тем же аккаунтом Google. Папку с большими файлами и список файлов смотри в `большие-файлы.md` (если там написано «не назначена», спроси у владельца название папки и впиши).
7. **Ключ OpenAI** нужен, только если на этом компьютере будут генерироваться картинки. Проверь `echo ${OPENAI_API_KEY:+есть}`; ключ в чате не показывай и в файлы не пиши. Если нужен, владелец сам добавляет его в `~/.zshrc`.
8. **Правило gh для пуша.** Обычный `git push` на Mac падает, пуш делается так: `git -c credential.helper= -c credential.helper='!/opt/homebrew/bin/gh auth git-credential' push origin HEAD`.
9. **Проверка синхронизации.** Сделай `git fetch`, `git status -sb`, `git log --oneline -3`. Затем создай и запушь пустую проверку (например добавь строку с датой и названием компьютера в `второй-компьютер.md`, коммит, пуш) и убедись, что пуш прошёл.
10. **Итог владельцу:** список «стоит / поставлено / осталось сделать ему», хэш последнего коммита.

## Рабочий порядок дальше (всегда)
- В начале сессии: `git fetch`, подтянуть свежее (`git pull --rebase` или влить `main`). Конфликт или расхождение: остановиться и сказать владельцу.
- После каждой законченной правки: коммит с понятным русским сообщением и пуш (правила в `CLAUDE.md`, раздел «Синхронизация между компьютерами»). Владелец этого не просит.
- В конце ответа: «синхронизировано, коммит <хэш>».
- Большие файлы класть в папку Google Диска и обновлять `большие-файлы.md`.
- Память Claude между компьютерами не переносится: всё важное писать в `CLAUDE.md`.

## Что НЕ синхронизируется само
Видео, звук, архивы (`*.mp4 *.mov *.mp3 *.wav *.zip`, кроме `ролики/*/озвучка.mp3`): только через Google Диск. Промежуточные файлы рендера (`razgon-animation-studio/projects/*/build/`) не переносим, они пересобираются рендером.
