# Настройка второго компьютера (один раз)

Файлы проекта приходят из GitHub, программы и ключи ставятся на каждый Mac отдельно.

1. Приложение Claude, вход в тот же аккаунт.
2. Git и GitHub CLI: `brew install git gh`, затем `gh auth login` (аккаунт Maxim771177, scope repo и workflow). `gh` лежит в `/opt/homebrew/bin/gh`, в PATH его может не быть.
3. Клонировать проект: `git clone https://github.com/Maxim771177/stick_what_if.git ~/stick_what_if`, открыть эту папку в приложении Claude, вкладка Code.
4. Node.js (`brew install node`), затем в `razgon-animation-studio` выполнить `npm install`.
5. Google Chrome (для рендера, путь через `CHROME_PATH`).
6. Google Диск для компьютера, вход в тот же аккаунт Google. Папка с большими файлами: см. `большие-файлы.md`.
7. Ключ `OPENAI_API_KEY` в `~/.zshrc` (только если на этом компьютере генерируем картинки). В файлы проекта ключ не пишем.
8. Проверка: сказать Claude «проверь настройку второго компьютера». Он сверит этот список и `git status`.

## Каждый раз при смене компьютера
- Уходишь: убедись, что в последнем ответе Claude написал «синхронизировано» с хэшем коммита.
- Приходишь: открой сессию, Claude сам сделает `git fetch` и подтянет свежее.
